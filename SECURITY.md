# Security Policy

## Reporting vulnerabilities

Please do not open public issues for security vulnerabilities.

Until a dedicated security contact is established, report privately to the repository owner.

## Supported versions

Compliance OS is pre-release. Security support is best-effort until the first tagged release.

## Security principles

- least privilege by default
- generated UI is not authoritative
- all meaningful writes go through capabilities
- high-risk actions require approval
- evidence integrity must be verifiable
- connector activity must have provenance
- regulatory updates must be reviewable before operational impact
- sandbox examples must not contain real personal data
